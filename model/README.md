# FSAE 2027 electric car, example model

`FSAE-2027-Electric-Arcadia.zip` (SHA-256 `66e693abfdf821af96f241ee707f74efe44939c4d7b3d63ef830169b075e1ba3`) is the
model every experiment in `../evals/harness-comparison/PROTOCOL.md` started from. It was built by the scripts in
`../fsae-acceptance` from the official Formula SAE Rules 2027 V1.0; see `../fsae-acceptance/README.md` for
what it does and does not establish. Open it in Capella 7.0 with Requirements Viewpoint 0.14.0.
